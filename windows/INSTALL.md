一二布布 Windows 免费测试版

目标：Windows 10 / Windows 11，64位 Intel 或 AMD 电脑。建议使用已更新的 Windows 10 22H2 或 Windows 11；不是32位或原生ARM64版本。不承诺所有历史Windows10版本。

1. 下载 YierBubu-Windows-x64-v0.5.0-beta.1.zip。
2. 右键压缩包选择“全部解压”，将整个 YierBubu 文件夹放到你喜欢的位置。
3. 双击文件夹里的 YierBubu.exe。无需安装.NET、Python、开发工具或管理员权限。
4. 在屏幕右下角托盘（可能在向上箭头里）找到小熊图标。右键可显示/隐藏、缩放、穿透、恢复位置、动作演示、查看真实计数或退出。
5. 切换到其他软件，按主键盘字母/数字、点击和滚动，观察动作与真实计数。动作演示不代表真实输入已验证。

程序未做商业代码签名，Windows可能提示无法识别发布者。请核对来源与SHA256，不要关闭安全软件；如被阻止或隔离，请保留提示信息用于反馈。本测试版不保证没有SmartScreen提示。

隐私：仅用当前物理键位、鼠标按钮和滚动驱动动作，不读取输入文字、不保存按键历史、不联网，不自动开机启动。次数仅在本次运行期间保留。

隐藏小熊不会停止监听。锁屏、睡眠和会话断开时暂停并清空按住状态；安全桌面、密码保护、特殊驱动或受保护程序等场景可能无法接收输入，不绕过系统限制。

更新：先从托盘退出旧版，再完整解压新版到新目录运行。不要只复制EXE或Assets。卸载：从托盘退出，再删除整个YierBubu文件夹。

验证范围：云端Windows Server编译、核心测试、真实窗口与RawInput注册、程序渲染检查；尚无Windows10/11实体键鼠、Intel/AMD分别实测、多屏/长期运行验收。以RELEASE-INFO.json和项目验证记录为准。
