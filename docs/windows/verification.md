## 独立审查与回归

独立审查没有Critical；发现两个Important：窗口样式更新缺少显式不激活标志、多设备共用按住状态。均已处理。多设备回归先观察缺少实现失败，再实现每设备重复识别和跨设备逻辑按住聚合；68项全绿。焦点问题没有在云端复现为实际抢焦点（测试前置条件不可满足），不伪称该项RED→GREEN。

一项Minor暂缓：设备接入通知和移除通知目前都会清空短暂按住状态；热插拔可能中断一次正在按住的动作，不产生长期卡键。后续可细分arrival/removal策略。

## 未覆盖与限制

- 没有Windows10/11实体键鼠的非零输入计数，也没有Intel/AMD分别实机验收；Raw Input API注册成功不等于实体输入成功。
- Windows10客户端未实际运行；Windows11客户端证据来自ARM上x64模拟。
- 混合DPI多屏、真实焦点/拖动、锁屏/睡眠长期行为、特殊驱动/保护软件仍待实机验证。
- 不承诺所有历史Windows10版本，不保证未签名程序无SmartScreen提示。

应用运行不联网、不读取输入文字、不记录输入历史、不发模拟输入；构建工具联网下载批准素材与微软运行库，不改变应用隐私约定。不会把演示、构建、API注册或渲染检查描述成物理硬件验收。
