## 已发布版本的历史验证

### Mac

核心33项、发布回归21项通过；Apple 芯片与 Rosetta 的窗口/动画检查各38项通过。用户反馈 MacBook Air 2020（Intel Core i5、8GB、macOS 15.7.9）重新授权后输入恢复。Rosetta 不等同于实体 Intel 实测，用户反馈不代表全部设备或长期场景验收。

### Windows

核心68项、本地素材/归档11项通过；公开树原有10项通过、1项私有资源检查跳过。Windows Server 2022/2025、Windows 11 ARM 上的 x64 模拟云端检查通过，包含50项固定窗口/绘图/生命周期检查，另1项交互式焦点按环境记录通过或未验证。

冻结安装包完成 x64 PE、自包含运行库、三张素材SHA256、运行库许可和 ZIP 逐文件解压验证，共485个文件。[冻结包工作流](https://github.com/Li-Jiangjiu/YierBubu/actions/runs/39651788326)

维护者随后已在旧 Windows 台式机运行并反馈可用，尚未补充实际系统版本和 CPU；包内 RELEASE-INFO 保留制作时状态，此反馈是后续补充。Windows 10各版本、Intel/AMD分别实机、混合DPI多屏、长期睡眠唤醒未全面验收。热插拔设备可能清空一次短暂按住状态。

## 如何理解持续集成

最新源码检查结果见仓库 Actions；请区分以上冻结包历史结果与后续源码提交的结果。图形冒烟检查窗口、渲染、状态和生命周期，不代表实际全局键鼠输入已获授权或实机输入成功。托管桌面的交互式焦点也可能受环境限制，必须按结果记录说明。

开发者修改后应在自己的目标系统确认输入、焦点、DPI、权限和休眠行为；不把某次CI或单台用户反馈扩大为所有电脑兼容。
